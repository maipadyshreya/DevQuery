# About 
DevQuery is an AI- powered software engineering interview practice app built with Streamlit.
The app asks software engineering interview questions, allows users to submit answers, and uses an AI model to score responses.

# How to Run the App

## Install required packages:

pip install streamlit pandas openai python-dotenv

## Create a .env file and add your NVIDIA API key:

NVIDIA_API_KEY=your_api_key_here

## Run the application:

streamlit run app.py
